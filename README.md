# html-review

Multi-page website reviewing the main HTML tags (Lab work 3, Amity University Tashkent).

Each page presents one family of tags with: **Definition**, **Attributes** (table), **Example (code)** and **Example (result)**.

## Pages

| File | Content |
|------|---------|
| `index.html` | Home and page structure |
| `text.html` | Text formatting tags |
| `links.html` | Links, images, video, audio |
| `lists.html` | Lists |
| `tables.html` | Tables |
| `forms.html` | Forms |
| `media.html` | Multimedia |
| `semantic.html` | Semantic and layout tags |
| `metadata.html` | Metadata |

All pages share `css/style.css`. Media files are in `images/`.
