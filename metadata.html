Tags placed in head that describe the page.

<title>

Definition

Sets the page title shown in the browser tab.

Attributes

AttributeRole
(none)Only global attributes

Example (code)

<title>HTML Review</title>

Example (result)

See the browser tab.

<meta>

Definition

Gives information about the page: encoding, description, viewport.

Attributes

AttributeRole
charsetCharacter encoding, e.g. UTF-8
nameType of metadata (description, viewport)
contentValue of the metadata

Example (code)

<meta charset="UTF-8">
<meta name="description" content="HTML review">

Example (result)

Not visible: used by browsers and search engines.

<link>

Definition

Links the page to an external resource, usually a CSS file.

Attributes

AttributeRole
relRelationship, e.g. stylesheet
hrefPath of the file

Example (code)

<link rel="stylesheet" href="css/style.css">

Example (result)

This page's design comes from style.css.

<script>

Definition

Embeds or links JavaScript code.

Attributes

AttributeRole
srcPath of the script file
deferRuns the script after the page is parsed

Example (code)

<script src="app.js" defer></script>

Example (result)

Not visible: runs in the background.
