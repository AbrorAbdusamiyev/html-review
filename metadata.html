Metadata

Tags placed in the head of the page. They describe the document and are not displayed in the page body.

<title>

Definition

Sets the title of the page shown in the browser tab and in search results. It goes in head.

Attributes

AttributeRole
(none)Only global attributes; the title text is written between the tags.

Example (code)

<title>HTML Review | Home</title>

Example (result)

Look at the browser tab: it shows the text of the title tag of this page.

<meta>

Definition

Gives information about the document (character set, description, author, viewport). It is an empty tag placed in head.

Attributes

AttributeRole
charsetCharacter encoding of the page, usually UTF-8.
nameKind of information: description, author, viewport, keywords.
contentValue of the information named by name.
http-equivSimulates an HTTP header, for example refresh.

Example (code)

<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<meta name="description" content="Review of the main HTML tags">
<meta name="author" content="Student names">

Example (result)

Metadata is invisible. It is read by the browser and by search engines. Use "View page source" to see the meta tags of this page.

<link>

Definition

Connects the page to an external resource, most often a CSS file or an icon. Empty tag placed in head.

Attributes

AttributeRole
relRelationship with the resource, for example stylesheet or icon.
hrefPath or URL of the resource.
typeMIME type of the resource, for example text/css.

Example (code)

<link rel="stylesheet" href="css/style.css">

Example (result)

This is how every page of this website receives its style from css/style.css.

<base>

Definition

Sets the base URL used for all relative links of the page. Only one base is allowed, in head.

Attributes

AttributeRole
hrefBase URL for all relative links.
targetDefault target for all links, for example _blank.

Example (code)

<base href="https://example.com/" target="_blank">

Example (result)

The base tag is shown only as code here, because using it on this page would break the relative links of the menu.

<script>

Definition

Inserts JavaScript code into the page, or links to an external JavaScript file.

Attributes

AttributeRole
srcPath of an external JavaScript file.
deferRuns the script after the page is parsed.
asyncLoads the script without blocking the page.
typeType of script, for example module.

Example (code)

<script src="js/app.js" defer></script>

Example (result)

This website does not need JavaScript, so the tag is shown only as code.

<noscript>

Definition

Content displayed only when the browser has JavaScript disabled.

Attributes

AttributeRole
(none)Only global attributes.

Example (code)

<noscript>Please enable JavaScript.</noscript>

Example (result)

Nothing is displayed here as long as JavaScript is enabled in your browser.
