Review of the main HTML tags: definition, attributes and examples.

<!DOCTYPE html>

Definition

Declares that the document uses HTML5. It must be the first line.

Attributes

AttributeRole
htmlDocument type: HTML5

Example (code)

<!DOCTYPE html>

Example (result)

This page starts with this declaration.

<html>

Definition

Root element that wraps the whole page.

Attributes

AttributeRole
langLanguage of the page, e.g. en
dirText direction: ltr or rtl

Example (code)

<html lang="en">
  ...
</html>

Example (result)

The whole page is inside <html>.

<head>

Definition

Container for information about the page (title, meta, CSS link). It is not displayed.

Attributes

AttributeRole
(none)Uses only global attributes

Example (code)

<head>
  <title>My page</title>
</head>

Example (result)

Look at the browser tab: the title comes from <head>.

<body>

Definition

Contains everything visible: text, images, links, tables.

Attributes

AttributeRole
classCSS class name
idUnique identifier

Example (code)

<body>
  <h1>Hello</h1>
</body>

Example (result)

Hello (all visible content is in <body>)
