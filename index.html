Home &amp; Page Structure

Welcome! This website reviews the main HTML tags. Each page presents one family of tags with a Definition, an Attributes table and an Example shown as code and as a real result. This first page shows the structure of an HTML document.

<!DOCTYPE html>

Definition

Declares that the document is HTML5, so the browser renders the page in standards mode. It must be the very first line of the file.

Attributes

AttributeRole
(none)This tag has no specific attributes; only global attributes such as class and id apply.

Example (code)

<!DOCTYPE html>

Example (result)

The first line of every page in this website is <!DOCTYPE html>.

<html>

Definition

The root element of the page. All other elements are placed inside it.

Attributes

AttributeRole
langLanguage of the page content (for example en), used by browsers and screen readers.

Example (code)

<html lang="en">
  ...
</html>

Example (result)

Every page here starts with html lang="en".

<head>

Definition

Container for information about the page that is not displayed directly: title, metadata, links to CSS files.

Attributes

AttributeRole
(none)This tag has no specific attributes; only global attributes such as class and id apply.

Example (code)

<head>
  <meta charset="UTF-8">
  <title>My page</title>
  <link rel="stylesheet" href="css/style.css">
</head>

Example (result)

The head of this page contains the charset, the viewport, the title and the link to css/style.css. Use your browser's "View page source" to see it.

<body>

Definition

Contains everything that is visible in the browser window: text, images, links, tables, forms.

Attributes

AttributeRole
(none)This tag has no specific attributes; only global attributes such as class and id apply.

Example (code)

<body>
  <h1>Hello</h1>
  <p>Visible content.</p>
</body>

Example (result)

Everything you see on this page is inside the body tag.

<header>, <nav>, <main>, <footer>

Definition

The basic skeleton shared by all pages of this website: a header with the site title, a navigation menu, the main content and a footer.

Attributes

AttributeRole
(none)This tag has no specific attributes; only global attributes such as class and id apply.

Example (code)

<header>...</header>
<nav>
  <ul>
    <li><a href="index.html">Home</a></li>
  </ul>
</nav>
<main>...</main>
<footer>...</footer>

Example (result)

Look at the top (header + menu) and the bottom (footer) of this page: they are identical on all 9 pages.
