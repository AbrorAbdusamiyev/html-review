Tags that embed rich content.

<picture> and <source>

Definition

Lets the browser choose between several images.

Attributes

AttributeRole
srcsetImage file(s) for the source
mediaCondition, e.g. (min-width: 600px)

Example (code)

<picture>
  <source srcset="images/logo.svg" media="(min-width: 600px)">
  <img src="images/logo.svg" alt="Logo">
</picture>

Example (result)

<iframe>

Definition

Embeds another web page inside this page.

Attributes

AttributeRole
srcURL of the embedded page
widthWidth
heightHeight
titleDescription for accessibility

Example (code)

<iframe src="index.html" width="400" height="150" title="Home page"></iframe>

Example (result)

<canvas>

Definition

Area for drawing graphics with JavaScript.

Attributes

AttributeRole
widthCanvas width
heightCanvas height
idUsed by JavaScript to find it

Example (code)

<canvas id="c" width="200" height="60"></canvas>
