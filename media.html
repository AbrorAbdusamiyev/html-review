Multimedia

Tags used to embed pictures, frames, video and audio. The sample files are in the images/ folder.

<iframe>

Definition

Embeds another web page inside the current page.

Attributes

AttributeRole
srcURL of the page to embed.
titleDescription of the content (important for accessibility).
widthWidth of the frame.
heightHeight of the frame.
loadinglazy loads the frame only when it is near the screen.

Example (code)

<iframe src="index.html" title="Home page preview" width="400" height="200"></iframe>

Example (result)

<figure> and <figcaption>

Definition

figure wraps an illustration (image, diagram, code); figcaption is its caption.

Attributes

AttributeRole
(none)Only global attributes are used.

Example (code)

<figure>
  <img src="images/sample.svg" alt="Sample picture" width="300">
  <figcaption>Figure 1 - A sample picture</figcaption>
</figure>

Example (result)

<picture> and <source>

Definition

Lets the browser choose between several image files, for example depending on the screen width.

Attributes

AttributeRole
srcsetOn source: the image file(s) to use.
mediaOn source: a media query that must be true to use the file.
src / altOn the fallback img inside picture.

Example (code)

<picture>
  <source srcset="images/sample.svg" media="(min-width: 600px)">
  <img src="images/sample.svg" alt="Responsive picture" width="250">
</picture>

Example (result)

<video> with <source>

Definition

Several formats of the same video can be offered with source tags; the browser plays the first one it supports.

Attributes

AttributeRole
srcOn source: path of the file.
typeOn source: MIME type, for example video/mp4.
controlsOn video: shows the player controls.

Example (code)

<video controls width="320">
  <source src="images/sample.mp4" type="video/mp4">
  Your browser does not support the video tag.
</video>

Example (result)

<audio> with <source>

Definition

The same idea for sound files.

Attributes

AttributeRole
srcOn source: path of the file.
typeOn source: MIME type, for example audio/wav.
controlsOn audio: shows the player controls.

Example (code)

<audio controls>
  <source src="images/sample.wav" type="audio/wav">
  Your browser does not support the audio tag.
</audio>
