Forms

Tags used to collect information from the visitor. The forms below are only for demonstration; they send nothing.

<form>

Definition

Container that collects user input and sends it to a server.

Attributes

AttributeRole
actionURL of the page that receives the data.
methodHTTP method used to send the data: get or post.
nameName of the form.
targetWhere to display the response.

Example (code)

<form action="#" method="post">
  <label for="user">Name:</label>
  <input type="text" id="user" name="user">
  <button type="submit">Send</button>
</form>

Example (result)

<label>

Definition

Gives a text caption to a form control. Clicking the label focuses the control.

Attributes

AttributeRole
forThe id of the control that the label belongs to.

Example (code)

<label for="mail">E-mail:</label>
<input type="email" id="mail" name="mail">

Example (result)

<input>

Definition

The most used form tag. Its look and behaviour depend on the type attribute. It is an empty tag.

Attributes

AttributeRole
typeKind of field: text, password, email, number, checkbox, radio, date, submit...
nameName used when the data is sent.
valueDefault or sent value.
placeholderHint text shown while the field is empty.
requiredThe field must be filled before sending.
checkedPre-selects a checkbox or radio button.

Example (code)

<input type="text" name="city" placeholder="Your city" required>
<input type="password" name="pass" placeholder="Password">
<input type="checkbox" id="c1" name="c1" checked>
<label for="c1">I agree</label>
<input type="radio" id="r1" name="gender" value="m">
<label for="r1">Male</label>
<input type="radio" id="r2" name="gender" value="f">
<label for="r2">Female</label>

Example (result)

<textarea>

Definition

A multi-line text field.

Attributes

AttributeRole
rowsVisible number of lines.
colsVisible width in characters.
nameName used when the data is sent.
maxlengthMaximum number of characters.

Example (code)

<textarea name="msg" rows="4" cols="30" placeholder="Write your message"></textarea>

Example (result)

<select> and <option>

Definition

select creates a drop-down list; each choice is an option.

Attributes

AttributeRole
nameName used when the data is sent.
valueOn option: the value sent to the server.
selectedOn option: the choice selected by default.
multipleOn select: allows choosing several options.

Example (code)

<select name="course">
  <option value="html">HTML</option>
  <option value="css" selected>CSS</option>
  <option value="js">JavaScript</option>
</select>

Example (result)

<button>

Definition

A clickable button.

Attributes

AttributeRole
typesubmit (sends the form), reset (clears it) or button (does nothing by itself).
nameName of the button.
disabledMakes the button unusable.

Example (code)

<button type="submit">Send</button>
<button type="reset">Reset</button>

Example (result)

<fieldset> and <legend>

Definition

fieldset groups related controls inside a box; legend is the title of that group.

Attributes

AttributeRole
disabledDisables all the controls inside the group.
nameName of the group.

Example (code)

<fieldset>
  <legend>Contact</legend>
  <label for="ph">Phone:</label>
  <input type="tel" id="ph" name="ph">
</fieldset>
