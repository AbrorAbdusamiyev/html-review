Tags that collect data from the user.

<form>

Definition

Container for form controls.

Attributes

AttributeRole
actionWhere the data is sent
methodget or post

Example (code)

<form action="#" method="post">
  ...
</form>

Example (result)

See the examples below.

<label> and <input>

Definition

label = text for a field. input = a field; its type changes the control.

Attributes

AttributeRole
typetext, email, password, checkbox, radio, number, date
nameName of the data
idLinks the input to its label (for)
placeholderHint text
requiredField must be filled

Example (code)

<label for="n">Name:</label>
<input type="text" id="n" name="name" placeholder="Your name" required>

Example (result)

<select> and <option>

Definition

Drop-down list; each option is one choice.

Attributes

AttributeRole
nameName of the data
valueValue sent for an option
selectedOption chosen by default

Example (code)

<select name="lang">
  <option value="en">English</option>
  <option value="ru" selected>Russian</option>
</select>

Example (result)

<textarea>

Definition

Multi-line text field.

Attributes

AttributeRole
rowsVisible lines
colsVisible width in characters
nameName of the data

Example (code)

<textarea name="msg" rows="3" cols="30"></textarea>

Example (result)

<button>

Definition

A clickable button.

Attributes

AttributeRole
typesubmit, reset or button
disabledTurns the button off

Example (code)

<button type="submit">Send</button>
