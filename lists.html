Lists

Tags used to group items: bulleted lists, numbered lists and description lists.

<ul> and <li>

Definition

ul is an unordered (bulleted) list. Each item of the list is written in an li tag.

Attributes

AttributeRole
typeOld attribute for the bullet style (disc, circle, square); CSS list-style-type is preferred.
classCSS class name for styling.

Example (code)

<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>

Example (result)

  • HTML
  • CSS
  • JavaScript

<ol>

Definition

An ordered (numbered) list. The order of the items matters.

Attributes

AttributeRole
typeNumbering style: 1, A, a, I, i.
startNumber of the first item.
reversedCounts the items backwards.

Example (code)

<ol type="A" start="1">
  <li>Create the repository</li>
  <li>Clone it in VS Code</li>
  <li>Commit and push</li>
</ol>

Example (result)

  1. Create the repository
  2. Clone it in VS Code
  3. Commit and push

<dl>, <dt>, <dd>

Definition

A description list: dl is the list, dt is the term and dd is the description of the term.

Attributes

AttributeRole
classCSS class name for styling.

Example (code)

<dl>
  <dt>HTML</dt>
  <dd>Language used to build the structure of a web page.</dd>
  <dt>CSS</dt>
  <dd>Language used to style a web page.</dd>
</dl>

Example (result)

HTML
Language used to build the structure of a web page.
CSS
Language used to style a web page.

Nested lists

Definition

A list can be placed inside an li item of another list to build sub-levels.

Attributes

AttributeRole
(none)The inner ul or ol must be inside an li, before its closing tag.

Example (code)

<ul>
  <li>Front-end
    <ul>
      <li>HTML</li>
      <li>CSS</li>
    </ul>
  </li>
  <li>Back-end</li>
</ul>

Example (result)

  • Front-end
    • HTML
    • CSS
  • Back-end
