Tags that group items.

<ul>

Definition

Unordered (bulleted) list.

Attributes

AttributeRole
classCSS class

Example (code)

<ul>
  <li>HTML</li>
  <li>CSS</li>
</ul>

Example (result)

  • HTML
  • CSS

<ol>

Definition

Ordered (numbered) list.

Attributes

AttributeRole
typeNumbering style: 1, a, A, i, I
startFirst number
reversedCounts down

Example (code)

<ol type="A" start="3">
  <li>Plan</li>
  <li>Code</li>
</ol>

Example (result)

  1. Plan
  2. Code

<li>

Definition

One item inside ul or ol.

Attributes

AttributeRole
valueNumber of the item (in ol)

Example (code)

<li>Item</li>

Example (result)

  • Item

<dl>, <dt>, <dd>

Definition

Description list: dt = term, dd = its description.

Attributes

AttributeRole
(none)Only global attributes

Example (code)

<dl>
  <dt>HTML</dt>
  <dd>Page structure</dd>
</dl>

Example (result)

HTML
Page structure
