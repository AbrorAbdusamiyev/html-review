Tags that connect pages and embed files.

<a>

Definition

Creates a hyperlink to another page, file or website.

Attributes

AttributeRole
hrefDestination URL
target_blank opens a new tab
titleTooltip

Example (code)

<a href="index.html">Go Home</a>

Example (result)

Go Home

<img>

Definition

Displays an image.

Attributes

AttributeRole
srcPath of the image
altAlternative text
widthWidth in pixels
heightHeight in pixels

Example (code)

<img src="images/logo.svg" alt="Logo" width="160">

Example (result)

<video>

Definition

Embeds a video player.

Attributes

AttributeRole
srcPath of the video file
controlsShows play/pause buttons
widthPlayer width
posterImage shown before playing

Example (code)

<video src="images/sample.mp4" controls width="300"></video>

Example (result)

<audio>

Definition

Embeds a sound player.

Attributes

AttributeRole
srcPath of the audio file
controlsShows the player controls
loopRepeats the audio

Example (code)

<audio src="images/sample.mp3" controls></audio>
