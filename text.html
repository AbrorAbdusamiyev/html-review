Text Formatting Tags

Tags used to structure and format text: headings, paragraphs, emphasis, quotations and code.

<h1> to <h6>

Definition

Headings. h1 is the most important title and h6 the least important. Use only one h1 per page.

Attributes

AttributeRole
idUnique identifier, used as an anchor target or for CSS.
className of a CSS class used to style the heading.

Example (code)

<h1>Heading 1</h1>
<h2>Heading 2</h2>
<h3>Heading 3</h3>
<h4>Heading 4</h4>
<h5>Heading 5</h5>
<h6>Heading 6</h6>

Example (result)

Heading 1

Heading 2

Heading 3

Heading 4

Heading 5
Heading 6

<p>

Definition

Defines a paragraph of text. Browsers add space before and after it.

Attributes

AttributeRole
classCSS class name for styling.
idUnique identifier of the paragraph.

Example (code)

<p>This is a paragraph of text.</p>

Example (result)

This is a paragraph of text.

<br> and <hr>

Definition

br inserts a line break. hr draws a horizontal line to separate thematic parts. Both are empty (void) tags.

Attributes

AttributeRole
(none)Neither tag needs a closing tag or specific attributes.

Example (code)

<p>First line<br>Second line</p>
<hr>
<p>Text after the line</p>

Example (result)

First line
Second line

Text after the line

<strong> and <em>

Definition

strong marks text of strong importance (usually bold). em marks emphasized text (usually italic).

Attributes

AttributeRole
classCSS class name for styling.

Example (code)

<p>This is <strong>very important</strong> and <em>emphasized</em>.</p>

Example (result)

This is very important and emphasized.

<b>, <i>, <u>, <mark>, <small>

Definition

Visual formatting tags: bold, italic, underlined, highlighted and smaller text.

Attributes

AttributeRole
classCSS class name for styling.

Example (code)

<p><b>Bold</b>, <i>italic</i>, <u>underline</u>, <mark>highlighted</mark>, <small>small text</small>.</p>

Example (result)

Bold, italic, underline, highlighted, small text.

<sub> and <sup>

Definition

Subscript (lowered) and superscript (raised) text, used in formulas and footnotes.

Attributes

AttributeRole
classCSS class name for styling.

Example (code)

<p>Water: H<sub>2</sub>O &nbsp; Area: 5 m<sup>2</sup></p>

Example (result)

Water: H2O   Area: 5 m2

<blockquote> and <q>

Definition

blockquote is a long quotation displayed as a separate block. q is a short inline quotation with quotation marks.

Attributes

AttributeRole
citeURL of the source of the quotation.

Example (code)

<blockquote cite="https://developer.mozilla.org">
  HTML is the standard markup language for web pages.
</blockquote>
<p>He said: <q>Learning HTML is fun.</q></p>

Example (result)

HTML is the standard markup language for web pages.

He said: Learning HTML is fun.

<code> and <pre>

Definition

code shows a piece of computer code. pre keeps spaces and line breaks exactly as written (preformatted text).

Attributes

AttributeRole
classCSS class name for styling.

Example (code)

<pre><code>let x = 5;
let y = 10;
console.log(x + y);</code></pre>

Example (result)

let x = 5;
let y = 10;
console.log(x + y);

<span> and <div>

Definition

Generic containers with no meaning. span is inline (inside a line of text); div is a block (takes the full width).

Attributes

AttributeRole
classCSS class used to style the container.
idUnique identifier of the container.

Example (code)

<div class="box">This is a div (block).</div>
<p>A word in <span class="red">red</span> inside a paragraph.</p>

Example (result)

This is a div (block).

A word in red inside a paragraph.
