Tags that structure and format text.

<h1> – <h6>

Definition

Headings from the most important (h1) to the least important (h6).

Attributes

AttributeRole
idAnchor target for links
classCSS class

Example (code)

<h1>Title</h1>
<h2>Subtitle</h2>
<h3>Section</h3>

Example (result)

Title

Subtitle

Section

<p>

Definition

Defines a paragraph of text.

Attributes

AttributeRole
classCSS class
titleTooltip on hover

Example (code)

<p title="Info">A paragraph.</p>

Example (result)

A paragraph.

<strong> and <em>

Definition

strong = important text (bold). em = emphasized text (italic).

Attributes

AttributeRole
classCSS class

Example (code)

<p><strong>Important</strong> and <em>stressed</em>.</p>

Example (result)

Important and stressed.

<br> and <hr>

Definition

br = line break. hr = horizontal line between topics.

Attributes

AttributeRole
(none)Void tags: no closing tag

Example (code)

Line 1<br>Line 2
<hr>

Example (result)

Line 1
Line 2

Attributes

Example (result)

A quote.
