Semantic and Layout Tags

Tags that describe the role of each part of the page. They replace many anonymous div tags and help search engines and screen readers. Each page of this website uses them.

<header>

Definition

Introductory part of a page or of a section: logo, title, sometimes the menu.

Attributes

AttributeRole
(none)Only global attributes (class, id).

Example (code)

<header>
  <h1>My Website</h1>
  <p>Welcome</p>
</header>

Example (result)

My Website

Welcome

<nav>

Definition

A section that contains the main navigation links.

Attributes

AttributeRole
(none)Only global attributes.

Example (code)

<nav>
  <a href="index.html">Home</a> |
  <a href="text.html">Text</a>
</nav>

Example (result)

Home | Text

<main>

Definition

The main content of the page. There must be only one visible main per page.

Attributes

AttributeRole
(none)Only global attributes.

Example (code)

<main>
  <p>Main content of the page.</p>
</main>

Example (result)

Main content of the page.

<section>

Definition

A thematic group of content, usually with its own heading.

Attributes

AttributeRole
(none)Only global attributes.

Example (code)

<section>
  <h2>Our services</h2>
  <p>We build websites.</p>
</section>

Example (result)

Our services

We build websites.

<article>

Definition

Independent content that makes sense alone: a blog post, a news item, a comment.

Attributes

AttributeRole
(none)Only global attributes.

Example (code)

<article>
  <h2>News title</h2>
  <p>Short news text.</p>
</article>

Example (result)

News title

Short news text.

<aside>

Definition

Content related to the main content but separate from it: a side bar, an advertisement, a note.

Attributes

AttributeRole
(none)Only global attributes.

Example (code)

<aside>
  <h2>Did you know?</h2>
  <p>HTML was created in 1991.</p>
</aside>

Example (result)

Did you know?

HTML was created in 1991.

<footer>

Definition

Closing part of a page or section: author, copyright, contacts.

Attributes

AttributeRole
(none)Only global attributes.

Example (code)

<footer>
  <p>&copy; 2026 My Website</p>
</footer>

Example (result)

© 2026 My Website
