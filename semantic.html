Tags that give meaning to the parts of a page.

<header> and <footer>

Definition

header = top of a page or section. footer = bottom (author, copyright).

Attributes

AttributeRole
classCSS class

Example (code)

<header>Top</header>
<footer>Bottom</footer>

Example (result)

Top
Bottom

<nav>

Definition

Group of navigation links.

Attributes

AttributeRole
aria-labelDescribes the menu for screen readers

Example (code)

<nav>
  <a href="index.html">Home</a>
</nav>

Example (result)

Home

<main>

Definition

The main content of the page. Use only one per page.

Attributes

AttributeRole
(none)Only global attributes

Example (code)

<main>Content</main>

Example (result)

Content

<section> and <article>

Definition

section = thematic group. article = independent content (post, news).

Attributes

AttributeRole
idAnchor target
classCSS class

Example (code)

<section>
  <article>Post</article>
</section>

Example (result)

Post

<aside>

Definition

Side content related to the main text.

Attributes

AttributeRole
classCSS class

Example (code)

<aside>Side note</aside>

Example (result)

Side note

<figure> and <figcaption>

Definition

figure groups media; figcaption is its caption.

Attributes

AttributeRole
(none)Only global attributes

Example (code)

<figure>
  <img src="images/logo.svg" alt="Logo" width="120">
  <figcaption>Our logo</figcaption>
</figure>

Example (result)
