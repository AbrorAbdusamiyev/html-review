Tables

Tags used to display data in rows and columns. The tables on this website use the class demo-table and attr-table for their style.

<table>, <tr>, <th>, <td>

Definition

table creates a table; tr is a row; th is a header cell (bold and centered); td is a normal data cell.

Attributes

AttributeRole
borderOld attribute for the border width; use CSS border instead.
colspanNumber of columns a cell spans.
rowspanNumber of rows a cell spans.
scopeOn th: says if the header is for a col or a row.

Example (code)

<table>
  <tr>
    <th>Name</th>
    <th>Age</th>
  </tr>
  <tr>
    <td>Ali</td>
    <td>20</td>
  </tr>
  <tr>
    <td>Sara</td>
    <td>21</td>
  </tr>
</table>

Example (result)

Name Age
Ali 20
Sara 21

<caption>

Definition

Gives a title to the table. It must be the first child of table.

Attributes

AttributeRole
(none)No specific attributes; position is controlled with CSS caption-side.

Example (code)

<table>
  <caption>Student list</caption>
  <tr><th>Name</th><th>Group</th></tr>
  <tr><td>Ali</td><td>A1</td></tr>
</table>

Example (result)

Student list
NameGroup
AliA1

<thead>, <tbody>, <tfoot>

Definition

Group the rows of a table into a header part, a body part and a footer part.

Attributes

AttributeRole
(none)Only global attributes; they help styling and accessibility.

Example (code)

<table>
  <thead>
    <tr><th>Item</th><th>Price</th></tr>
  </thead>
  <tbody>
    <tr><td>Book</td><td>10</td></tr>
    <tr><td>Pen</td><td>2</td></tr>
  </tbody>
  <tfoot>
    <tr><td>Total</td><td>12</td></tr>
  </tfoot>
</table>

Example (result)

ItemPrice
Book10
Pen2
Total12

colspan and rowspan

Definition

Attributes that merge cells horizontally (colspan) or vertically (rowspan).

Attributes

AttributeRole
colspanMerges the cell with the next cells of the same row.
rowspanMerges the cell with the cells below it.

Example (code)

<table>
  <tr>
    <th colspan="2">Schedule</th>
  </tr>
  <tr>
    <td rowspan="2">Monday</td>
    <td>HTML</td>
  </tr>
  <tr>
    <td>CSS</td>
  </tr>
</table>

Example (result)

Schedule
Monday HTML
CSS
