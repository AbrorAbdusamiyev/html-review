Tags that display data in rows and columns.

<table>, <tr>, <th>, <td>

Definition

table = the table, tr = row, th = header cell, td = data cell.

Attributes

AttributeRole
borderBorder width (old style)
classCSS class

Example (code)

<table>
  <tr><th>Tag</th><th>Role</th></tr>
  <tr><td>p</td><td>Paragraph</td></tr>
</table>

Example (result)

TagRole
pParagraph

<caption>

Definition

Title of a table.

Attributes

AttributeRole
(none)Only global attributes

Example (code)

<table>
  <caption>Tags</caption>
  <tr><td>a</td></tr>
</table>

Example (result)

Tags
a

<thead>, <tbody>, <tfoot>

Definition

Group the header, body and footer rows.

Attributes

AttributeRole
(none)Only global attributes

Example (code)

<table>
  <thead><tr><th>Item</th></tr></thead>
  <tbody><tr><td>Pen</td></tr></tbody>
  <tfoot><tr><td>Total: 1</td></tr></tfoot>
</table>

Example (result)

Item
Pen
Total: 1

colspan and rowspan

Definition

Attributes of th/td that merge cells.

Attributes

AttributeRole
colspanNumber of columns to merge
rowspanNumber of rows to merge

Example (code)

<table>
  <tr><th colspan="2">Merged</th></tr>
  <tr><td>A</td><td>B</td></tr>
</table>

Example (result)

Merged
